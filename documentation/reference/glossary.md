# Глосарій

Терміни, які трапляються в коді та в цій документації. Назви термінів залишено англійською, як у коді. Основу взято з [`docs/reference/template-glossary.md`](https://github.com/Blazheiko/itvibe-template/blob/main/docs/reference/template-glossary.md); кожне визначення звірено з кодом і доповнено термінами з інших сторінок сайту.

| Термін                      | Значення                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Де докладніше                                                                         |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| API playground              | Vue-застосунок для розробників і QA ([`packages/api-playground`](https://github.com/Blazheiko/itvibe-template/blob/main/packages/api-playground)). Він завантажує опис маршрутів з `GET /api/doc/routes` і дає вручну викликати HTTP- і WS-маршрути. Працює лише в manual-test mode                                                                                                                                                                                          | [API Playground](/playground/), [Маршрутизація](/backend/routing-middlewares)         |
| AppResult                   | `AppResult<T> = ResultType<T, AppError>` з [`services/shared/errors.ts`](https://github.com/Blazheiko/itvibe-template/blob/main/packages/backend/src/app/services/shared/errors.ts). Це результат сервісу, який замість винятку несе або значення, або типізовану помилку. Контролер мапить її в HTTP-статус                                                                                                                                                                 | [Контролери та сервіси](/backend/controllers-services)                                |
| Branded type                | Тип-примітив із фантомною міткою, що розрізняє семантично різні значення. Приклад: `UserId = string & { readonly [__userIdBrand]: true }` у [`normalize-user-id.ts`](https://github.com/Blazheiko/itvibe-template/blob/main/packages/backend/src/vendor/utils/helpers/normalize-user-id.ts)                                                                                                                                                                                  | [Shared](/shared/)                                                                    |
| CSRF                        | Cross-site request forgery. Захист підключається middleware `csrf_guard` для небезпечних методів (`post`, `put`, `patch`, `delete`) за наявності сесії. За замовчуванням `CSRF_ENFORCE=false`, тобто порушення лише логуються                                                                                                                                                                                                                                                | [Автентифікація та безпека](/backend/auth-security#csrf)                              |
| Synchronizer-token CSRF     | Модель CSRF, у якій сервер зберігає `csrfToken` (32 байти, base64url) у сесії, а клієнт надсилає його в заголовку `x-csrf-token`. Порівняння виконується через `timingSafeEqual` ([`csrf-guard.ts`](https://github.com/Blazheiko/itvibe-template/blob/main/packages/backend/src/app/middlewares/csrf-guard.ts))                                                                                                                                                              | [Автентифікація та безпека](/backend/auth-security#csrf)                              |
| defineRoute / defineWsRoute | Хелпери оголошення HTTP- і WS-маршрутів з `handler`, схемами запиту/відповіді та описом ([`http-routes.ts`](https://github.com/Blazheiko/itvibe-template/blob/main/packages/backend/src/app/routes/http-routes.ts))                                                                                                                                                                                                                                                          | [Маршрутизація](/backend/routing-middlewares)                                         |
| Embedding                   | Векторне представлення тексту для пошуку в базі знань. Колонка `embedding` має тип `vector(1536)` у [`schema.ts`](https://github.com/Blazheiko/itvibe-template/blob/main/packages/backend/src/database/schema.ts)                                                                                                                                                                                                                                                            | [AI](/backend/ai), [База даних](/backend/database)                                    |
| ETag                        | Валідатор кешу для статики, яку віддає сервер. Відповідь `304` повертається, коли збігається `If-None-Match`                                                                                                                                                                                                                                                                                                                                                                 | [Кешування та ETag](/backend/caching-etag#etag)                                       |
| Knowledge base              | Статті підтримки, якими керує адмін (маршрути `/admin/knowledge-base*`). Вони використовуються в support AI для пошуку за embedding                                                                                                                                                                                                                                                                                                                                          | [AI](/backend/ai#support-ai-і-база-знань)                                             |
| Manual-test mode            | Режим `APP_ENV=manual-test`. Разом з `DOC_PAGE=true` і `SERVE_STATIC=true` вмикає ендпоінт `/doc/routes` для API playground ([`server.ts`](https://github.com/Blazheiko/itvibe-template/blob/main/packages/backend/src/vendor/start/server.ts)). Запускається через `pnpm dev:manual_test`                                                                                                                                                                                   | [Маршрутизація](/backend/routing-middlewares#інтроспекція-маршрутів-і-api-playground) |
| Middleware                  | Функція `(context, next)` у ланцюжку маршруту: `session_web`, `csrf_guard`, `auth_guard`, `admin_guard` та ін.                                                                                                                                                                                                                                                                                                                                                               | [Маршрутизація](/backend/routing-middlewares)                                         |
| pgvector                    | Розширення PostgreSQL `vector`, потрібне для колонки embedding. `db:create` виконує `CREATE EXTENSION IF NOT EXISTS vector`                                                                                                                                                                                                                                                                                                                                                  | [База даних](/backend/database)                                                       |
| Presence                    | Облік автентифікованих користувачів, підключених через WebSocket. [`ws-presence-service.ts`](https://github.com/Blazheiko/itvibe-template/blob/main/packages/backend/src/app/services/communication/ws-presence-service.ts) на connect/disconnect оновлює онлайн-стан і розсилає події `admin_user_online_upsert` / `admin_user_online_remove` в адмін-канал                                                                                                                 | [WebSocket](/backend/websocket)                                                       |
| Production-like mode        | `appConfig.isProductionLike`: `APP_IS_PRODUCTION`, а якщо її не задано, то `APP_ENV`/`NODE_ENV` зі значенням `production`/`prod`. Вмикає `__Host-`-cookie і забороняє fake SMS                                                                                                                                                                                                                                                                                               | [Конфігурація](/backend/configuration#production-like-режим)                          |
| Промпти (retained prompt)   | Збережені системні промпти AI, які адмін редагує і тестує (маршрути `/prompts`). У бекенді терміна «retained prompt» немає (фраза «retained support prompts» є лише в тексті [`AiPolicy.vue`](https://github.com/Blazheiko/itvibe-template/blob/main/packages/frontend/src/views/AiPolicy.vue)): у коді це таблиця `llm_system_prompts` (`llmSystemPrompts` у [`schema.ts`](https://github.com/Blazheiko/itvibe-template/blob/main/packages/backend/src/database/schema.ts)) | [AI](/backend/ai#промпти)                                                             |
| Repository                  | Шар доступу до БД через Drizzle, наприклад [`user-repository.ts`](https://github.com/Blazheiko/itvibe-template/blob/main/packages/backend/src/app/repositories/user/user-repository.ts). Сервіси працюють з таблицями через репозиторії                                                                                                                                                                                                                                      | [Репозиторії та трансформери](/backend/repositories-transformers)                     |
| Session                     | Стан автентифікованого браузера в Redis. Клієнт тримає його ідентифікатор у HTTP-only cookie ([`config/session.ts`](https://github.com/Blazheiko/itvibe-template/blob/main/packages/backend/src/config/session.ts)). Middleware `session_web`                                                                                                                                                                                                                                | [Автентифікація та безпека](/backend/auth-security#сесіі)                             |
| Support chat                | Чат користувача з AI-агентом підтримки через WebSocket (WS-маршрути `support_open_chat`, `support_chat`) та HTTP-історія `/support/chat/history`                                                                                                                                                                                                                                                                                                                             | [AI](/backend/ai), [WebSocket](/backend/websocket)                                    |
| Transformer                 | Функція серіалізації рядка БД у публічну форму. Наприклад, [`user-transformer.ts`](https://github.com/Blazheiko/itvibe-template/blob/main/packages/backend/src/app/transformers/user-transformer.ts) прибирає `password` і `sessionToken`, а `id` і дати перетворює на рядки                                                                                                                                                                                                 | [Репозиторії та трансформери](/backend/repositories-transformers)                     |
| VAPID                       | Пара ключів, що ідентифікує сервер для Web Push. Публічний ключ віддається на `GET /push-subscriptions/vapid-public-key`                                                                                                                                                                                                                                                                                                                                                     | [Пошта та push](/backend/mail-push#vapid-ключі)                                       |
| WebSocket token             | Токен, який повертають `/main/init` та `/main/update-ws-token` (обидва під `auth_guard`). Його зберігають у Redis на 60 с ([`generate-ws-token-service.ts`](https://github.com/Blazheiko/itvibe-template/blob/main/packages/backend/src/app/services/auth/generate-ws-token-service.ts)), і фронтенд передає його при WS upgrade                                                                                                                                             | [WebSocket](/backend/websocket#отримання-токена-по-http)                              |
