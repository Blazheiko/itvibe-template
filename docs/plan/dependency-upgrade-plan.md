## 1. Загальні правила для кожного етапу

1. Один етап — один коміт або PR з повідомленням `chore(deps): …` чи `feat(deps): …`.
2. Після кожного етапу:
   ```sh
   pnpm install
   pnpm build && pnpm typecheck && pnpm lint && pnpm test
   pnpm --filter frontend exec vitest run
   pnpm audit
   ```
   Якщо етап зачіпає UI, додатково запускаємо `pnpm --filter frontend test:e2e`.
3. Версії backend фіксуємо точно, без `^`, як уже заведено в `packages/backend/package.json`. Для frontend і api-playground лишаємо `^`.
4. Якщо етап не проходить і причину не вдається знайти за розумний час, відкочуємо його (`git revert`), а проблему записуємо в розділ 9.
